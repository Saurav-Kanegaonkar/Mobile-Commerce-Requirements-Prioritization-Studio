# Data Sources

Synthetic source-style data for mobile commerce requirements and prioritization.

- `entities.csv`: 36 product request records.
- `daily_metrics.csv`: 5,040 product request-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
